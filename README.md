# Nafru Email SDK'ları

Nafru Email için resmi SDK'lar. Hepsi aynı sürümle yayınlanır ve aynı anda kullanımdan kaldırılır.

| Dil | Kurulum | Belge |
| --- | --- | --- |
| TypeScript / JavaScript | `npm install @nafrucom/email` | [npm](https://www.npmjs.com/package/@nafrucom/email) |
| Python | `pip install nafru-email` | [python/](python/README.md) |
| Go | `go get github.com/nafrucom/nafru-email-sdks/go` | [go/](go/README.md) |
| PHP | `composer require nafrucom/email` | [php/](php/README.md) |
| Ruby | `gem install nafru-email` | [ruby/](ruby/README.md) |
| Java | `com.nafru:nafru-email` | [java/](java/README.md) |
| .NET | `dotnet add package Nafru.Email` | [dotnet/](dotnet/README.md) |
| Rust | `cargo add nafru-email` | [rust/](rust/README.md) |
| Swift | `.package(url: "https://github.com/nafrucom/nafru-email-sdks", from: "0.1.0")` | [swift/](swift/README.md) |

## Kullanımdan kaldırılan sürümler

[`deprecations.json`](deprecations.json) kaldırılan sürümleri listeler. Böyle bir sürüm API'den `Deprecation` (ve varsa `Sunset`) başlığı alır;
SDK bir kez uyarı basar, çağrılar çalışmaya devam eder.

Bu depo, kaynağın yayın sırasında oluşturulan aynasıdır; değişiklik önerileri için issue açın.
